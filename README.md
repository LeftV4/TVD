# TVD - Hotel Management System

A Java-based hotel management application developed as part of a Database Technologies course project. The system is designed to support hotel operations through a JavaFX desktop interface backed by PostgreSQL.

## Overview

TVD is a hotel management system for managing reservations, room information, staff/admin workflows, and user access in a relational database environment. The application combines a desktop front end with SQL-backed data handling to support day-to-day hotel operations.

## Tech Stack

- Java 17+
- JavaFX for the desktop user interface
- PostgreSQL for the database layer
- SQL scripts for schema and procedures
- Maven for project build and dependency management
- IntelliJ IDEA / Java development environment

## Features

- Role-based sign-in for users, staff, and administrators
- Room and accommodation management
- Reservation and booking workflow support
- Administrative dashboard for hotel operations
- Database-driven logic using SQL stored procedures and functions
- Desktop interface with custom styling and UI panels
